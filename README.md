# 📻 Radio FM

تطبيق أندرويد كلاسيكي احترافي للاستماع إلى جميع الإذاعات المغربية، يعمل على الهواتف وأجهزة التلفاز.

## ✨ المميزات
- 🎵 جميع الإذاعات المغربية في مكان واحد
- 📺 يعمل على الهاتف والتلفاز (Android TV)
- 🎨 تصميم كلاسيكي أنيق بألوان ذهبية
- 🎮 دعم كامل للتحكم بأزرار التلفاز (D-Pad)
- ▶️ مشغل احترافي بأزرار التشغيل والإيقاف

## 🛠️ التقنيات
- Kotlin
- Jetpack Compose
- Media3 ExoPlayer
- Material 3

## 🚀 التشغيل
1. افتح المشروع في Android Studio
2. اضغط Sync Gradle
3. شغّل التطبيق
